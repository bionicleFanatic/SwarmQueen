# SwarmQueen
A Jump King mini-clone built for Neuro-Sama

How to set up for NeuroSDK:
* Open the game once.
* Open the save file at C:\Users\ <username> \AppData\Roaming\Godot\app_userdata\SwarmQueen\
* Change the Websocket var to the address the SDK is using
* Reload the game and Neuro will start playing
